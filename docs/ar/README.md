## 1. الصورة الكبيرة

- إي-سداد **هو الذي يتصل بخادمك**. أنت لا تتصل به.
- توجد **3 طلبات XML** وطلب واحد لفحص الجاهزية.

| #   | الطلب                          | متى؟                                | كودك يجيب على                       |
| --- | ------------------------------ | ----------------------------------- | ----------------------------------- |
| 1   | **PrepaidValidation**          | قبل دفعة **مسبقة الدفع** (شحن رصيد) | "هل العميل موجود؟ هل المبلغ مقبول؟" |
| 2   | **BillPull**                   | قبل دفع **فاتورة**                  | "ما فواتير هذا العميل؟"             |
| 3   | **ReceivePaymentNotification** | **بعد** أن يدفع العميل              | "سجّل هذه الدفعة."                   |
| 4   | **Availability**               | في أي وقت                           | لا شيء، المكتبة تجيب.               |

💡 خدمتك شحن رصيد فقط؟ تحتاج **1 + 3** فقط.

### ما تفعله المكتبة عنك

- ✅ تقرأ الـ XML وتتحقق منه
- ✅ تتحقق من **توقيع** إي-سداد، فيُرفض أي طلب مزيّف
- ✅ توقّع ردّك
- ✅ تسجّل كل طلب وكل رد
- ✅ لا تسجّل الدفعة نفسها مرتين حتى لو أعاد إي-سداد الإرسال
- ✅ تنسّق المبالغ حسب العملة (الدينار `10.000`، الشيكل `10.00`)
- ✅ لا ترسل تفاصيل أخطائك الداخلية إلى إي-سداد

## 2. التشغيل في 5 خطوات

### ✅ قبل البدء

- [ ] Node.js إصدار **22.23.5** أو **24.22.3** أو **26.13.1** فما فوق (`node -v`)
- [ ] مشروع Express (أو أي إطار آخر)

### الخطوة 1: التثبيت

```bash
npm install github:zaqoutabed/e-sadad-xml express
```

### الخطوة 2: مفاتيح تجريبية 🔑

```bash
bash node_modules/e-sadad-xml/examples/dev-keys.sh
```

ينشئ مجلد `dev-keys/`. ⚠️ أضفه إلى `.gitignore` ولا ترفع المفاتيح إلى git أبداً.

### الخطوة 3: ملف الخادم

```js
import express from 'express';
import { EsadadService, InMemoryStore, normalizeMobileNumber } from 'e-sadad-xml';
import { createEsadadRouter } from 'e-sadad-xml/express';

const esadad = new EsadadService({
  // 1️⃣ من أنت
  biller: { code: 999, name: 'My Company' }, // قيمة وهمية: ضع رمز المفوتر من إي-سداد

  // 2️⃣ ماذا تبيع
  services: [
    {
      serviceType: 'MOBILE_TOPUP',
      paymentType: 'PrePaid',
      currency: 'ILS',
      bankCode: 99,
      iban: 'PS00XXXX000000000000000000000', // قيمة وهمية: ضع الآيبان الخاص بك
    },
  ],

  // 3️⃣ مفاتيحك
  certificates: {
    esadadCertificate: { path: 'dev-keys/esadad-dev.cer' },
    billerPfx: { path: 'dev-keys/biller-dev.pfx', password: 'dev-password' },
  },

  // 4️⃣ رقم الفوترة = رقم الجوال (970599… تصبح 0599…)
  normalizeBillingNo: normalizeMobileNumber,

  // 5️⃣ كودك أنت
  adapter: {
    async validatePrepaid(request) {
      const exists = request.billingNo.startsWith('059'); // ← ابحث في قاعدة بياناتك
      return { valid: exists };
    },
    async postPayment(trx) {
      console.log(`شحن ${trx.billingNo} بمبلغ ${trx.paidAmount} (مرجع ${trx.joebppsTrx})`); // ← نفّذ الشحن
    },
  },

  // 6️⃣ أين تُحفظ السجلات (استخدم قاعدة بيانات في الإنتاج)
  store: new InMemoryStore(),
  availabilityToken: 'dev-token',
  logger: console,
});

const app = express();
app.use('/api/v1/esadad', createEsadadRouter(esadad));
app.listen(3000, () => console.log('جاهز على http://localhost:3000/api/v1/esadad'));
```

### الخطوة 4: التشغيل

```bash
node server.mjs
```

```bash
curl "http://localhost:3000/api/v1/esadad/availability?token=dev-token"
```

النتيجة: `{"status":"success", ...}` 🎉

## 3. كودك أنت

كودك يعيش في مكان واحد اسمه **adapter**: كائن فيه حتى 3 دوال. اكتب فقط ما تحتاجه.

### 1️⃣ `validatePrepaid`: هل يمكن لهذا العميل أن يشحن؟

| الحالة              | أرجِع                                         |
| ------------------- | -------------------------------------------- |
| ✅ مقبول            | `{ valid: true }`                            |
| ❌ العميل غير موجود | `{ valid: false }` ← الرمز **408**           |
| ❌ سبب آخر          | `{ valid: false, result: 'INVALID_AMOUNT' }` |

### 2️⃣ `getBills`: ما فواتير هذا العميل؟

| الحالة              | أرجِع                                              |
| ------------------- | ------------------------------------------------- |
| ❌ الحساب غير موجود | `{ found: false }` ← الرمز **408**                |
| 🧾 عليه فواتير      | `{ found: true, bills: [{ billNo, dueAmount }] }` |
| 🆓 لا شيء مستحق     | `{ found: true, bills: [{ dueAmount: 0 }] }`      |

### 3️⃣ `postPayment`: العميل دفع، سجّل الدفعة

| الحالة        | ماذا تفعل                                              |
| ------------- | ------------------------------------------------------ |
| ✅ تم التسجيل | لا تُرجع شيئاً                                           |
| ❌ مرفوضة     | `{ success: false, result: 'INVALID_BILLING_NUMBER' }` |
| 💥 نظامك معطّل | ارمِ خطأ (`throw`): إي-سداد سيعيد المحاولة لاحقاً        |

⭐ **احفظ `trx.joebppsTrx` كمرجع فريد للدفعة** (مع قيد unique في قاعدة بياناتك).

### 🛡️ الدفع المزدوج: محلول

```
إي-سداد يرسل الدفعة 9001   ← postPayment تعمل ✅
إي-سداد يعيد إرسال 9001    ← postPayment لا تعمل، والرد "Success"
```

### 📣 رسالة SMS بعد الدفع؟

لا تضعها داخل `postPayment`. استخدم **hooks**: تعمل في الخلفية ولا تؤخر الرد.

```js
hooks: {
  async onPaymentPosted(trx) {
    await sms.send(trx.billingNo, `تم شحن رصيدك بمبلغ ${trx.paidAmount}`);
  },
},
```

## 4. الأخطاء

- طلبات XML ترجع **دائماً HTTP 200**. الخطأ يكون **داخل** الـ XML.
- تفاصيل أخطائك الداخلية **لا تُرسل أبداً** إلى إي-سداد، بل تذهب إلى الـ logger فقط.

| الرمز   | المعنى                              | مؤكَّد من إي-سداد؟ |
| ------- | ----------------------------------- | ---------------- |
| **0**   | نجاح                                | ✅               |
| **2**   | توقيع غير صحيح                      | ✅               |
| **408** | رقم فوترة غير صحيح                  | ✅               |
| 1       | طلب غير صالح (XML تالف، GUID ناقص…) | ⏳ افتراضي       |
| 3       | اسم مستخدم أو كلمة مرور خاطئة       | ⏳ افتراضي       |
| 4       | رمز المفوتر ليس لك                  | ⏳ افتراضي       |
| 5       | نوع خدمة غير معروف                  | ⏳ افتراضي       |
| 6       | عملة لا تطابق الخدمة                | ⏳ افتراضي       |
| 7       | مبلغ غير صالح                       | ⏳ افتراضي       |
| 500     | خطأ عام (التفاصيل في سجلاتك)        | ⏳ افتراضي       |

⏳ = رقم افتراضي من المكتبة. غيّره عندما يؤكد إي-سداد الأرقام الرسمية:

```js
resultCodes: { INVALID_AMOUNT: { code: 13, desc: 'Invalid Amount', severity: 'Error' } },
```

لإرسال خطأ خاص بك من الـ adapter:

```js
throw new EsadadError({ code: 410, desc: 'Account Suspended', severity: 'Error' });
```

## 5. قاعدة البيانات

- الـ **store** يحفظ سجلات الطلبات والردود وسجلات الدفعات، وهو الذي **يمنع الدفع المزدوج**.
- `InMemoryStore` للتجربة فقط: ينسى كل شيء عند إعادة التشغيل. 🚫 لا تستخدمه في الإنتاج.

| قاعدة البيانات | الجداول                                                           | الكود                                                       |
| -------------- | ----------------------------------------------------------------- | ----------------------------------------------------------- |
| SQL Server     | [`schema.sqlserver.sql`](../../examples/sql/schema.sqlserver.sql) | [`sqlServerStore.ts`](../../examples/sql/sqlServerStore.ts) |
| PostgreSQL     | [`schema.postgres.sql`](../../examples/sql/schema.postgres.sql)   | [`postgresStore.ts`](../../examples/sql/postgresStore.ts)   |

1. شغّل ملف الجداول على قاعدة بياناتك.
2. انسخ ملف الـ store إلى مشروعك.
3. مرّره: `store: new PostgresStore(pool)`.

## 7. قائمة الإطلاق

### اطلب من إي-سداد

- [ ] رمز المفوتر (مثال: `999`)
- [ ] رموز الخدمات ورمز البنك والـ IBAN
- [ ] شهادة إي-سداد العامة (`.cer`)
- [ ] أرقام رموز الأخطاء الرسمية
- [ ] عناوين IP الخاصة بهم

### أعطِ إي-سداد

- [ ] شهادتك العامة (`.cer` المطابقة لملف `.pfx`)
- [ ] روابط خادمك (HTTPS)

### عندك

- [ ] الشهادات الحقيقية، محمّلة من **متغيرات البيئة** أو مدير أسرار، وليست في git
- [ ] `store` على قاعدة بيانات
- [ ] `postPayment` تحفظ `joebppsTrx` بقيد **unique**
- [ ] **HTTPS فقط**
- [ ] لا تسجّل روابط الطلبات كاملة في سجلات الخادم (كلمة المرور والـ token يأتيان في الرابط)
- [ ] `verifySignature` لا تساوي `false` أبداً

## 8. حل المشاكل

| المشكلة                        | الحل                                                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| 🔴 دائماً `2 Invalid Signature` | تأكد أن `esadadCertificate` هي شهادة **إي-سداد** وليست شهادتك. لا تضع `express.json()` قبل مسارات إي-سداد. |
| 🔴 التطبيق يتوقف عند التشغيل   | اقرأ رسالة `EsadadConfigError`: تذكر المشكلة بالاسم (كلمة مرور خاطئة، عملة غير مدعومة…).                   |
| 🟠 دائماً `408`                 | اطبع `request.billingNo`: القيمة بعد التنظيف هي `0599…` وليست `970599…`.                                   |
| 🟠 `5`                         | اسم الخدمة غير موجود في `services`، أو خدمة مسبقة الدفع طُلبت كفاتورة.                                      |
| 🟠 `7`                         | المبلغ صفر أو سالب، أو خارج `lowerValue` و`upperValue`.                                                    |
| 🟠 `500`                       | كودك رمى خطأ غير متوقع. **انظر إلى الـ logger.**                                                           |
| 🟡 `/availability` ترجع 503    | لم تضبط `availabilityToken`.                                                                               |
